\# Olist E-Commerce Sales Analysis



\## Project Overview

This project analyzes e-commerce order data using MySQL to identify sales trends, popular product categories, payment methods, and customer ordering patterns.



\## Tools Used

\- MySQL

\- MySQL Workbench

\- SQL



\## Analysis Performed

\- Order and customer counts

\- Payment method analysis

\- Top products by quantity sold

\- Category-wise sales revenue

\- Monthly sales trends

\- Top customers by order frequency



\## SQL Skills Demonstrated

\- SELECT and WHERE

\- Aggregate functions: COUNT, SUM

\- GROUP BY and ORDER BY

\- JOIN

\- DATE\_FORMAT

\- LIMIT



\## Key Findings

\- Home category generated the highest revenue among the analyzed categories.

\- Sports had the highest total quantity sold.

\- Cash was the most frequently used payment method in the dataset.

\- Monthly revenue varied across the observed period.



\## Dataset

The project uses orders, products, and customers CSV files.
